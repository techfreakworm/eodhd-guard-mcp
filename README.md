# eodhd-guard-mcp

A guard-first [MCP](https://modelcontextprotocol.io) server for the [EODHD](https://eodhd.com) market-data API.

> **Work in progress.** The design is in [docs/DESIGN.md](docs/DESIGN.md). Installation and usage docs follow with the first release.

This is an unofficial project. It is not affiliated with or endorsed by EODHD (Unicorn Data Services). You need your own EODHD subscription, and EODHD's licence terms apply to the data you fetch.
